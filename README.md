# Excel Data Analysis Project

**Project:** Sales Data Analysis using Microsoft Excel\
**Track:** Data Analytics\ Task : 5\
**Tools:** Microsoft Excel, formulas, PivotTables, and charts

## About the Project

This project analyzes sales data in Microsoft Excel to summarize sales
performance and explore differences across regions, product categories,
and dates. The goal is to organize the data, calculate key metrics, and
present useful findings in a clear and understandable format.

## Tools Used

-   Microsoft Excel
-   Excel formulas (including multiplication, subtraction, `SUM`, and
    `COUNTA`)
-   PivotTables
-   Charts and summary tables

## What the Project Covers

1.  Review and clean the source sales data.
2.  Calculate Sales and Profit in the working sheet.
3.  Summarize key metrics such as Total Sales, Total Orders, Total
    Quantity, and Total Profit.
4.  Compare sales by region.
5.  Compare sales by product category.
6.  Analyze region-versus-category performance.
7.  Review sales by date/month using a PivotTable.
8.  Write key findings and a conclusion based on the results.

**Important validation note:** These figures are provisional and must be

entries such as `Formula2`, `dc`, and a blank date. Do not treat the
figures as final until the source data and totals have been verified.

## How to Use the Workbook

1.  Open `Excel_Data_Analysis_Project.xlsx` in Microsoft Excel.
2.  Check that all Order Date values are valid Excel dates and correct
    any invalid entries.
3.  Verify the Sales and Profit formulas in the Working sheet.
4.  Refresh the PivotTables after correcting the source data.
5.  Confirm that the Summary KPIs match the cleaned data.
6.  Review the regional, category, region-versus-category, and monthly
    sales analyses.

## Limitations

-   The Monthly Sales PivotTable requires date cleanup and refresh
    before its results can be considered final.
-   Findings depend on the accuracy and completeness of the source sales
    data.
-   The final KPI values should be rechecked after the formulas and
    PivotTables are corrected.
